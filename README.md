## Projects

### [Readcue](https://getreadcue.com)

A Chrome extension for people who read English and keep hitting words with five dictionary meanings. Select a word. It reads the sentence around it and shows the sense that fits. No new tab.

I built the extension, the FastAPI backend, auth, and the site. Lookups go to DeepSeek. Accounts sit on Neon. The API runs on Fly.io. Explanations come in 10 languages.
